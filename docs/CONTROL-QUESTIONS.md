# Ответы на контрольные вопросы

1. **Для чего нужен `CEnemyTemplate` и почему сеттеры приватные?**  
   Класс хранит параметры одного типа противника. Приватные сеттеры запрещают произвольное изменение отдельных параметров снаружи: корректное состояние задаётся через конструктор.

2. **Зачем нужны `GetEnemyByName` и `GetEnemyByIndex`?**  
   Список является приватной деталью реализации. Методы дают контролируемый доступ к элементам и позволяют позднее изменить способ хранения без изменения пользовательского кода.

3. **Что такое сериализация и десериализация?**  
   Сериализация преобразует объекты в формат для хранения или передачи — здесь в JSON. Десериализация восстанавливает объекты из JSON после следующего запуска программы.

4. **Чем свойство отличается от приватного поля и `getName()`? Зачем `[JsonInclude]`?**  
   Свойство — стандартная конструкция C#, которая используется как поле, но предоставляет управляемый доступ через `get` и `set`. `[JsonInclude]` явно указывает сериализатору включать свойство с непубличным сеттером в JSON-контракт.

5. **Какая библиотека работает с JSON?**  
   Используется `System.Text.Json`. В .NET 8 она входит в платформу и подключается директивой `using System.Text.Json`; отдельный пакет обычно не нужен.

6. **Почему применяется ручная конвертация через `JsonDocument`?**  
   Она наглядно показывает чтение каждого свойства, позволяет проверить типы и значения, вызвать конструктор класса и выдать точную ошибку для конкретного элемента файла.

7. **Как загружаются изображения?**  
   Пользователь выбирает папку через `OpenFolderDialog`. Метод `EnemyIconCatalog.LoadIconsFromFolder` находит PNG-файлы и создаёт для каждого объект `EnemyIcon` с именем и полным путём.

8. **Для чего используется `SelectionChanged`?**  
   Событие сообщает, что пользователь выбрал другой элемент `ListBox`. Обработчик сохраняет имя выбранной иконки и показывает её как главную иконку противника.

9. **Чем отличаются `OpenFileDialog` и `SaveFileDialog`?**  
   `OpenFileDialog` выбирает существующий файл для чтения. `SaveFileDialog` получает путь для записи нового или замены существующего файла и может запросить подтверждение перезаписи.

10. **Зачем активно использовать Git?**  
    Git сохраняет этапы разработки и облегчает поиск ошибок и командную работу. Удачные сообщения описывают результат: `feat(icons): add folder icon loader`, `feat(json): save enemy templates`, `fix(validation): reject negative life`.

11. **Что дают отдельные ветки?**  
    Они изолируют изменения, позволяют независимо тестировать эксперимент, проводить review в Pull Request и не нарушать стабильную ветку `main` до завершения работы.
